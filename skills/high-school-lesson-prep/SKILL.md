# 高中数理化生家教备课

面向高一至高三的一对一家教。把资料转成能讲、能练、能检查学习效果的内容；纳入教学的每道题，都给教师提供经核查的解题过程。

## 选择工作流

| 用户的任务 | 读取并执行 |
| --- | --- |
| 备课、找资料、章节复习、组卷、编学习单 | [工作流一：备课与资料整合](workflows/prepare-lesson.md) |
| 按备课主题联网找讲义、课件、题库并下载入库 | [主题资料搜集、下载与归档](references/online-material-collection.md) |

| 发题、错题、题目截图、求解、一题多解、找方法、问学生为什么做错 | [工作流二：解题与讲题](workflows/solve-question.md) |
| 从用户提示、指定PDF或参考答案收录方法，核验候选、去重、纠错 | [工作流三：解题方法收录与维护](workflows/maintain-methods.md) |

联网时使用 `chinese-material-search`，并读取 [资料检索与来源核验](references/research-sources.md) 中的教学要求。它优先检索微信公众号，核对正文和附件状态；本技能据此选材、核解并组织授课。涉及解题、出题或科学结论时，读取 [四科学科检查](references/subject-checks.md) 中对应部分。

## 目录与权限约定

本发布方法库仅保存方法内容、条件、实例、核验状态和方法定位，不保存方法的获取途径、书名作者、网页链接、页码或阅读台账。必要的来源核查仍完成，相关过程记录留在本次会话或用户另指定的非发布工作区，不写入 `references/method-library/`。此约定优先于参考工作流中涉及来源持久化的通用说明。

本技能以所在文件夹为基准，随包方法库位于 `references/method-library/`，先读其中的 `index.md`。其它参考文件中提到的 `references/method-library` 也相对技能根目录解析，不相对参考文件所在目录。

外部题库目录、索引目录和下载位置由当前用户指定；未提供题库时不扫描未知目录，继续使用随包方法库、用户给出的题目和允许访问的来源。方法维护在没有外部题库时仍检查正文、总索引和JSON，跳过外部题库扫描并如实说明。下载与网盘操作仅在当前用户的授权范围内进行，已明确授权的范围无需重复确认。联网工具不存在或用户要求离线时，完成可离线处理的部分并说明限制。

## 本地题库

本地题库使用当前用户指定的目录。**每次备课、组卷或找题先按 [本地题库读取与增量更新](references/local-question-bank.md) 扫描一次**，报告与上次成功扫描相比新增、修改和移除的资料；首次只建立基线。用户指定其它目录或明确跳过时按要求处理。单独讲解用户已经给出的题目不强制扫描整库。

按本课主题先找本地候选，再实际读取选中的题干、图表和答案。文件索引只证明资料存在，不能代替阅读、题目年代核实或独立求解。“新增”指新收录的资料文件，尚未逐题拆分或判重，不能把文件数量说成新题数量。题库更新摘要交给教师，不放进学生练习版。

## 每次备课自动搜集网络资料

每次高中备课按本课主题查找相关讲义、课件和题库；当前用户已授权下载并指定保存位置时，将可取得的匹配文件归档并更新索引。在同一授权范围内不重复询问；尚未授权下载时交付链接与阅读状态。按 [主题资料搜集、下载与归档](references/online-material-collection.md) 执行：先检查本地资料，再实际联网，下载匹配资料、核验与去重、归档和记录来源；有新文件或修改时，在全部归档完成后执行一次索引更新。

原有本地题库够用时仍做一次与本课主题相关的网络检索；只有用户明确限制离线、只用本地或不下载时才相应缩减。只收集当前课题需要的小批资料，不承诺每次都有新文件。单独讲一道已给出的题，不强制启动搜集流程。夸克网盘操作须符合当前用户对本次任务的授权范围；需要用户登录或扫码时请其完成，继续处理其它可下载资料。

## 按题查找与积累解题方法

工作流二默认先识别学科、题型、条件和先修，再查本机 `references/method-library` 并按题联网寻找适用方法；找到后仍须独立推导和验证，未找到时继续自主求解。优先讲清主解法，再比较有实质不同思路的补充解法；不为数量重复同一推导或强用超纲方法。检索、停止条件和方法卡维护见 [方法库规范](references/solution-method-library.md)。单独发题不强制扫描整库或制作60分钟教案；本轮已有同题型的可读来源时复用检索。

## 默认设置与澄清

用户单独要求补方法、复核或整理方法库时走工作流三；讲题和备课中新出现值得复用的路线、适用边界或错误也调用其随题维护分支。方法维护只交付更新与核验结果，不强制套师生两版。

- 中文，高中课程范围，教师详解版＋学生练习版。用户指定单版、提纲或简短回答时按要求缩减。
- 备课未给时长时暂按60分钟一对一课；讲单题不强套整节课。教材、地区、年级和学生水平未知的项目明确记为“未提供”，不冒认教材章节或高考题源。
- 复用本聊天中已提供的学生信息。缺少普通偏好时写明暂定条件并继续；题图不清、关键条件缺失或不同解释会改变答案时，只追问影响求解的部分，先完成不受影响的内容。
- 用户的课时、教材、进度、教学方法优先。高一/高二/高三不机械对应某一固定章节；高三也需要先诊断再决定复习深度。

## 两版的共同约定

教师版包含目标、讲法、所有题的解答、关键依据、错因与纠正、来源及未核实项。学生版包含必要概念、完整题干、活动与作答空间，默认不附练习答案或教师批注。

**先确定共同题目清单和稳定题号，再分别生成两版。** 所有供学生作答的例题、诊断题、变式、课后题、开放问答、判断题均进入清单；教师版逐题提供答案及必要过程。开放题给参考要点和可接受的不同答案。用户后续增删题目时同步更新两版，避免题号错位。

给出可供授课的推导、计算、证据和检查，不只给答案或外部链接。原资料答案错误时，说明错误位置、正确结论和学生可理解的纠正方式。只为选入本次教学的题目负责，不把一次备课扩展成无限搜题。

## 工具与交付

- 使用宿主已有的搜索、浏览、文件、OCR和计算工具，名称与用法以当前环境为准；不假设所有 agent 都有某个连接器。可并行检索独立来源，最后统一核查题号与结论。
- 符号计算、画图、OCR只在有帮助时使用；计算结果需解释回高中知识。工具不可用就如实说明，手工推导仍可完成的内容继续做。需要另装依赖时只安装任务所需部分，遵守本次权限；安装不能解开平台登录限制。
- 执行 Python 计算时检测当前环境可用的解释器；不假设特定盘符、用户名或虚拟环境已存在。
- 默认在聊天交付清楚分隔的两版。用户需要文件或内容较长且宿主支持文件时，保存为独立的 `teacher-notes.md`、`student-worksheet.md` 文件并给可点击链接；默认Markdown，需要打印或指定格式时再生成Word/PDF。文件生成后检查可读性、题号、公式和答案隔离。
- “发给我”默认在当前聊天提供内容或文件，不自行发邮件、私信、群消息或上传学生信息。备课材料本身不要求安装新软件或购买资源。
- 最后简述已完成内容、来源访问限制和需要下次补充的信息；不声称两版已实际授课或学生已经掌握。
