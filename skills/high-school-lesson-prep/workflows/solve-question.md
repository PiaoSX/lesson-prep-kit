# 工作流二：按题检索方法、核解与讲题

发题 → 读清条件 → 判断学科、题型和先修 → 检索本地方法与网络候选 → 筛选适用路线 → 各法独立推导、交叉核验 → 比较讲法与迁移 → 积累方法卡。

检索用于发现和比较路线，独立核解贯穿所有分支。没有网络匹配不等于没有方法，更不等于新方法；找到参考解也不免除条件检查和验算。

## 1. 读清题目并定位

保留原符号、数据、单位与目标。截图先核对上下标、选项、几何关系、图例和标注；识别不清且会改变解答时，只追问关键部分，继续可确定部分。区分原题与另编的变式。

简要记录学科及交叉学科、知识点、题型（计算/证明/选择/图表/实验等）、已知与所求、关键限制和学生已学方法。教材、地区、学生基础未提供时据实注明，不把年级当作已学导数的证明。跨学科题分别检查各科模型。

用户只发题时，默认给教师可讲的解答，不扩为整课。用户指定解法、只要提示/答案、离线或限时要求时，以该要求控制方法与输出深度；只要提示时不给最终结论或完整备用解。

## 2. 寻找方法，核对匹配条件

读取 [方法库规范](../references/solution-method-library.md)，从本地总索引及相应学科卡查候选；实际阅读适用条件、步骤与失效情形，不能只看方法名。用“学科＋知识点＋题型＋解法/一题多解/适用条件”等关键词实际联网，执行 chinese-material-search 与 [来源核验](../references/research-sources.md)。默认把检索作为讲题的一步，不因自足计算题直接省略；已有本轮核实的同题型来源可复用，不对一组同类题重复搜索。

公众号用于发现路线；规律、课程边界与证明优先核对教材、出版社、教研机构、学校/作者原发资料。摘要或“秒杀技巧”仅作候选，不直接当已核解法；受阻页面按来源规范停止，不绕行。用必要题型关键词检索，不上传学生个人信息或完整私人错题档案。

通常一轮主题检索及必要的一轮换词足够。当主路线和有教学价值的补充路线已有可读依据且条件可验证时停止。未匹配、访问受限或耗时超出讲题用途时，记录范围与限制，转入独立求解。联网不可用写“本次未完成网络检索”，仍基于题干与可靠知识完成能完成的解答，不虚构来源。

为候选说明“哪条题设触发、哪些条件满足、学生是否学过”；不合适的写具体原因，不必向学生罗列所有排除过程。可先独立搭建方程或模型，与检索并行，避免照参考答案凑过程。

## 3. 独立完成每条采用路线

按 [四科学科检查](../references/subject-checks.md) 选择有效复核。优先提供最适合学生的主解；存在实质不同且有益的路线时，通常补充1—2种，不设必须凑够的数量。只改变量名、重排同一算式或更换计算软件不算另一方法。不同建模、关键定理或有独立推导的表征转换可构成有意义的第二路线。

每条采用方法都写关键步骤、条件和完整论证链，检查能否得到相同结论与解集。数学查定义域、等价变形、端点和取等；物理查对象、方向、量纲及守恒条件；化学查物种、介质、计量和反应限度；生物查遗传前提、样本空间、变量、证据和模型边界。多种分析路径不意味着科学事实可以随意选不同结论。

用代回、守恒、独立短解、极限或可读权威依据等匹配本题的方式验算。符号/数值工具可辅助；数值抽样与画图不能代替全称证明，软件输出不能代替授课推导。

答案冲突时回到题设与依据定位错误，给出错误步骤、正确结论与检查。分歧未消除的路线不能标为已验证或收入可复用实例。无自然第二解时交付主解，说明候选为何不适用；可补检验或条件变化，但不把检验包装成完整第二解。

## 4. 按学生能学会的顺序讲

教师详解包括题目与结论、方法识别、主解过程与检查、可用补充解、方法比较、可能错因和纠正，需要时给变式及其详解。比较围绕本题适用条件、先修、计算量、易错点和可迁移题型，说明课堂先讲哪条及理由，不把最快路线固定为最适合所有学生的路线。

可用紧凑表格：方法｜本题依据与条件｜步骤/计算量｜易错点｜适合怎样的学生。不编精确耗时或“万能”评价。生物与实验题可比较正向推理、反向排除、概率枚举、图表/变量证据等路径；不同实验方案须各自满足对照和证据要求。

例如x>0时求x+4/x的最小值：基本不等式给下界4，等号x=2；作差得(x−2)²/x≥0且边界可取。两法均解释正数条件与取等。未学导数时不把导数作为必备解法；若另编x>3的变式，要重新检查可达性，不能沿用“最小值4”。

## 5. 复用与归档

有新核实且值得复用的方法、旧卡缺少的边界或错误时，执行 [工作流三](maintain-methods.md) 的随题维护分支。复用本轮来源与演算，完成判重、补卡/纠错及索引同步；仅复用旧方法不重复写库。新推导标“本次独立推导并核验”，不宣称原创发现。受限来源与未解决方法保留候选状态。原题讲解先完成，不因维护故障阻止交付。

本次方法库有实际新增/修改时更新总索引，在全部写完后合并做一次题库文件索引更新；已有备课归档扫描时复用该轮更新。单独发题不必先扫全库，不因一道题启动整盘资料下载。

## 6. 学生版与交付核对

教师与学生版沿用相同题号、题干、图表、数据；新增变式给稳定题号，教师版给齐解答和检查。学生版保留作答空间，默认无答案、教师批注或答案文件链接；要求自学答案版时再附独立答案页。用户只要一版或简短讲解时不强制额外文件。

交付前核对：题意无误；各采用方法条件与结论一致；说明选择理由；没有把换写法算多解；教师覆盖全部任务；学生版无答案泄露；来源与方法库实际读写状态准确。已核查解法直接进入工作流一，不重复求解或重复本轮检索。
