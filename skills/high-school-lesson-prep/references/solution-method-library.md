# 解题方法库：检索、核验与积累

随包路径（相对技能根目录）：`references/method-library/`，入口为“index.md”，四科文件为“mathematics.md”“physics.md”“chemistry.md”“biology.md”。这是持续扩展的起点，不代表全网或全部高中方法已收齐；各科文件保留覆盖缺口。

## 查找与筛选

先读总索引，再按知识点、题型、别名全文检索少量卡片。例如：

    rg -n -e '最值' -e '配方' -e '基本不等式' 'references/method-library'

读命中卡片的完整条件和核验状态。question_bank.py search只查文件路径/名称，不能替代方法全文搜索。未命中可换常用别名，如净/表观光合、动能定理/功和能、三段式/ICE，再按题联网找原理、方法和反例。

同轮已读的同题型来源可复用；每题仍检查实际前提。方法库缺失或盘符不可用时，继续有限联网和独立求解，记录放到当前可写工作区，并注明默认方法库未更新。其它机器先检测路径，不照搬盘符。

## 卡片内容与状态

每卡用稳定ID，如MATH-01、PHYS-01、CHEM-01、BIO-01。维护以下实质信息，已有完整卡不必每次机械重写：

| 字段 | 内容 |
| --- | --- |
| 名称、别名与题型线索 | 知识点、任务和触发信息；跨科类比只作提示 |
| 适用条件与先修 | 定义域、模型、介质、遗传/实验假设及学生是否学过 |
| 步骤与检查 | 可操作的关键推导，不只写“用守恒”等名称 |
| 失效情形/反例 | 条件变化如何使方法误用，界是否可达 |
| 核验状态与实例 | 已核原理、已演算实例、待专题补核分别说明；标原创/改编并给检查，不写“万能正确” |

只有名称或缺少可检查的依据时，可在发布目录外记录候选，不能称完整推导已核查。原理有依据不表示在任意具体题中可用；热度、技巧名称或与答案一致不能替代条件与论证。

## 按科定位的起点

| 学科 | 先检查 | 常见路线方向 |
| --- | --- | --- |
| 数学 | 定义域、量词、参数、等价性、取等 | 配方/恒等变形、换元、不等式、函数/导数、数形、坐标向量、分类、计数概率 |
| 物理 | 对象、过程、方向、约束、外力作用 | 牛顿/运动学、功和能、冲量/动量、整体隔离、矢量、图像、电路等效 |
| 化学 | 物种、条件、反应限度、计量口径 | 方程比例、元素/电子守恒、平衡表与Q/K、差量、盖斯、实验流程证据 |
| 生物 | 模型前提、样本空间、变量、证据范围 | 配子枚举、概率拆分/逆推、假说检验、控制变量、图表、物质能量收支 |

这些是检索方向，不要求每题全部使用。第二解应有不同建模、关键论证或有教学价值的表征；只换符号或工具不计新方法。生物可比较分析路径或有效实验方案，不把互相矛盾的机制猜测当作两套正确解。

## 保存、更新与报告

从用户提示、指定PDF和不同参考答案收录方法，以及专题补缺、复核候选、合并与纠错，统一执行 [工作流三：解题方法收录与维护](../workflows/maintain-methods.md)。工作流一、二发现值得复用的新路线或边界时进入随题分支，直接复用本轮来源与演算；单独维护不生成整课。仅查看或复用不制造写入。

维护时以学科卡为正文依据，同步总索引和“methods.json”的ID、名称、状态、定位及计数。新触及条目的别名、核验状态和更新时间按工作流三保存；不将来源或获取途径字段写入发布方法索引。候选、部分核验和停用内容保持可辨，不升级为已核结论。

当前用户要求讲题和方法维护且允许写入时，可整理本库；只读或离线限制按用户要求执行；不覆盖用户其它资料，不写入学生个人信息。按需短述和链接；下载真实附件沿用 [下载归档流程](online-material-collection.md)。

本轮全部方法卡、实例和其它资料写完后，有实际变更才统一做一次题库文件扫描；JSON另作解析校验。方法维护与备课下载共享末次扫描，不为验证再次扫描。失败时分开报告题目核解、方法写入和索引更新的实际状态。教师摘要区分新增、补充、纠错、候选和复用，文件数不充当方法或题目数。
