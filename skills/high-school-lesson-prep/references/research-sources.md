# 资料检索与来源核验

网络资料发现使用 `chinese-material-search`：同级配套技能入口为 [中文资料检索](../../chinese-material-search/SKILL.md)。先执行该技能的公众号优先检索与正文/附件核验，再按本文件检查教学适用性、题源与解法；同一轮搜索结果可复用。若迁移后该技能不可用，继续按本文件的查询与有限重试步骤完成检索，不因缺少附加技能而停住备课。

每次备课还要执行 [主题资料搜集、下载与归档](online-material-collection.md)：当前用户已授权下载时，归档本课相关、可取得的讲义/课件/题库，保存到 `<用户指定题库目录>` 并更新索引。只给链接不能代替已具备条件的文件归档；没有合格文件时如实说明。

单独讲题时执行 [工作流二](../workflows/solve-question.md) 的方法检索：查询题型、方法原理与适用条件，保留实际已读来源；无需为一道题机械搜索所有教学平台或启动整套资料下载。既有同轮来源可复用。新方法和边界按 [方法库规范](solution-method-library.md) 积累。

## 找什么，怎样停止

先围绕教材边界和本课难点确定资料缺口：科学依据、可视化、教学情境、典型题、错因或练习。教材/课程标准/原始试卷用于确认口径和题源，出版社与教研机构用于教学参考，个人文章与视频用于讲法候选；热度不等于正确。

备课时优先尝试微信公众号，同时做通用或官方检索，并按教学缺口尝试B站、小红书的相关搜索。优先使用现有搜索与浏览工具。平台内搜索不可用时可做站外检索：

```text
高中 物理 牛顿第二定律 教学设计 site:mp.weixin.qq.com
高中 化学 催化剂 化学平衡 site:bilibili.com/video
高一 数学 函数 单调性 板书 site:xiaohongshu.com
高中 生物 伴性遗传 易错点 site:xhslink.com
```

加入教材版次、章节别名和学生难点；查询只是示例，不是现成结果。无结果或访问受限时，换一组关键字或一个当前可用访问方式即可；再次失败就记入限制，继续其它来源。用户给出特定链接时针对它核查。资料足够支撑本课目标后停止，不追求无限搜集。

## 访问状态决定能说到哪里

| 实际取得的内容 | 可以使用的范围 |
| --- | --- |
| 正文、图片、可读原卷或完整视频/字幕已查看 | 使用已查看部分，标明改写/引用；视频只对核实片段给时间戳 |
| 仅部分段落、部分字幕、预览页面 | 只根据可读部分提出结论，其余标为未读 |
| 搜索摘要、标题、作者、平台元数据 | 作为待查看候选；不能声称看过全文/视频或核实其中答案 |
| 登录页、验证码、拒绝访问、付费墙、空页面 | 标明受限，不补写正文，不编造题目或账号信息 |
| 用户提供的截图/文字 | 可核查可见内容，不能推断其原文其余部分 |
| 本地题库的文件名、目录或更新索引 | 作为待阅读候选；新增收录不代表新命题，不能声称已核实题干或答案 |
| 已实际读取的本地试题、图表与解析 | 使用已查看部分，保留绝对路径、页码或章节及原题号；答案仍须独立核查 |

平台登录由用户在合适界面操作；不索取密码、令牌或Cookie，不绕过付费或访问限制。普通网页抓取失败时，若已有授权浏览器中可以查看，可使用该能力；不能承诺每次都能看全平台。工具明确以站点安全策略阻止访问时，停止获取该受阻内容，不换浏览器、接口或镜像绕过；可改用独立可访问的公开资料并注明原文未核验。不要仅为打开一条受限笔记就安装不明爬虫。

联网不可用时明确标记“未完成本次网络检索”，仍可基于用户题目和可靠基础知识制作临时材料；不给虚构链接。搜索摘要不会升级为全文证据。

## 来源记录与采用

每条采用材料记录：原文标题、作者/机构或UP主、平台、直接URL、发布日期（不明即注明）、访问日期、实际可读范围、本课用途、适用教材/章节（未确认就注明）、核查结论。避免大表中反复填写相同信息，可在条目里合并记录。

本地资料用绝对路径、PDF页码或文档章节及原题号代替平台与URL，记录读取日期和可读范围。作者、原始来源与题目年份未知时据实注明；文件修改时间和文件名中的年份不能单独证明题源。具体操作见 [本地题库读取与增量更新](local-question-bank.md)。

公众号或网站附件独立记录领取条件、入口和文件取得/检查状态。“正文可读”“发现下载链接”“文件已取得”“文件已打开检查”分别说明；需要关注、回复关键词或登录时，仅报告已看到的条件。未取得的附件不当成已采用的教学材料，也不把公开可读直接写成开源授权。

具体结论附近放原文链接；候选来源与已采用来源分开。视频推荐说明要解决哪个教学难点、观看长度或已核实片段。引用试题需核实地区、年份、卷种、题号；未见原卷则不标成确定真题。自己写的题或改动数据的题明确标注。

逐题独立求解，答案分歧给出核查依据；教学事实区分定义、适用条件、教材简化、类比与现实系统。实验/演示优先选安全的公开演示、模拟或课堂可用方案；涉及危险化学品、明火、高压等时不把演示视频改成让学生在家操作的实验任务。

按教学需要摘要和链接，遵守来源许可与当前工具的引用限制，不整段搬运文章或复制整套付费题库。学生姓名、成绩、联系方式和可识别错题记录不上传给无关第三方服务。

## 可维护的起点

以下是入口，不代表已经阅读某节具体课；每次实际备课仍须搜索、打开、记录当次访问情况：

- [教育部](https://www.moe.gov.cn/)：核对课程标准与正式通知。
- [课程教材研究所](https://www.ictr.edu.cn/)：课标资料、解读及教研信息；[学术交流目录](https://www.ictr.edu.cn/policy/cheng/p/12.html)是一个可检索入口。
- [国家中小学智慧教育平台](https://basic.smartedu.cn/)：按学段、学科、版本和章节找课；动态页面取得空正文不能当作课程已经看过。
- [人民教育出版社](https://www.pep.com.cn/)：核对人教版教材及学科入口；[产品检索](https://www.pep.com.cn/products/search/)可辅助识别版本，不等于免费全文教材库。其它版本使用对应出版社入口。

**不要把某次访问结果或某版课标硬编码为长期现行**；按学生入学年份、地区教材和学校进度核对适用版本。
