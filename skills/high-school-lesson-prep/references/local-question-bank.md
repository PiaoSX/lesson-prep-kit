# 本地题库读取与增量更新

题库根目录与索引目录由当前用户指定。尚未指定时不启动扫描；继续处理不依赖外部题库的部分。扫描包含题库的子目录。每次备课、组卷、找题或用户要求检查更新时，先扫描，再按本课主题检索并读取候选。单独求解已给出的题目时无需同步整库。题库盘符不可用时说明限制，不能报告“无新题”。

## 扫描与更新摘要

用本技能附带的 `scripts/question_bank.py`。脚本只依赖 Python 标准库，不读取全库正文、不解压、不执行题库文件，也不改动原始资料。首次运行时检测可用 Python。以下 PowerShell 示例从仓库根目录运行；安装到其它位置后，将 `$bankTool` 改为实际脚本路径。题库及索引目录需由用户确认，索引目录不能等于题库根目录。

```powershell
$prepPython = (Get-Command python -ErrorAction Stop).Source
$bankTool = (Resolve-Path './skills/high-school-lesson-prep/scripts/question_bank.py').Path
$bankRoot = Read-Host '请输入题库绝对路径'
$stateDir = Join-Path $bankRoot '.lesson-prep-bank'
& $prepPython $bankTool scan --root $bankRoot --state-dir $stateDir
```

在指定的索引目录保存 `manifest.json`、`changes.json` 和 `question-bank-updates.md`。输出数量是资料文件数，不是逐道题目数。发布版要求扫描显式传入 `--root` 和 `--state-dir`，搜索使用同一 `--state-dir`；不再使用原作者机器的默认路径。

- 首次成功扫描：报告“已建立题库基线，共收录 N 份资料”，不把既有资料标成新增。
- 后续成功扫描：报告“相较上次扫描新增 A 份、修改 B 份、移除 C 份资料”，附本课相关的新增/修改文件示例。无变化时一句“本次未发现题库文件变化”即可。
- 变化依据是相对路径、文件大小和高精度修改时间；同大小且保留修改时间的内容替换可能漏检。重命名或移动暂记为移除＋新增。文件名年份、创建时间、修改时间均不等于命题时间。
- 忽略 Office `~$` 锁文件、临时文件和非资料程序；压缩包只登记为待查看资源。索引不会把同名不同目录的文件合并。
- 路径缺失、扫描不完整或旧清单损坏时，不覆盖上次清单，也不把未读到的资料算作移除。报告错误后继续不受影响的备课部分。不要通过删除旧索引掩盖扫描失败。

一次备课开始时扫描一次，直接保留返回的摘要和变更记录；检索过程不反复扫描。**本轮网络资料下载并归档完成后，若有新增或修改文件，再统一扫描一次并检查这些文件已进入索引**；本轮未新增或修改题库文件时不额外扫描。用户另行添加资料并要求刷新时也可再次扫描。

第二次扫描会替换 `changes.json` 和 `question-bank-updates.md` 的“最近一次”内容；因此在本课收集记录中保留首次摘要和本轮归档文件列表，向教师分别报告本地原有变化与网上入库结果。说明文件计入扫描数量时单独列明；不把两次统计简单相加，也不要为了验证而再扫描到“无变化”。具体流程见 [主题资料搜集、下载与归档](online-material-collection.md)。

更新在本次备课聊天中提示。每次备课会在当前用户已授权的范围内搜索和下载相关网络资料；未开启备课时不后台监控或主动推送。

## 按主题检索候选

```powershell
& $prepPython $bankTool search --state-dir $stateDir --query '基因工程' --query '基因编辑' --limit 10
& $prepPython $bankTool search --state-dir $stateDir --query '基因工程' --changes-only --limit 10
```

多个 `--query` 是候选关键词的“或”关系，用章节别名扩大覆盖；需要更精确时换成更具体的短语，或按返回路径筛选。`--changes-only` 仅查看最近一次成功扫描中新增、修改的匹配资料；入库后的第二次扫描不包含开工时已记录的全部变化，不能据此回填首次摘要。搜索只查文件名和相对路径，**不是全文检索**；没有命中不能断言题库没有相应题目。先换一组主题别名，再从相关目录选少量资料读取，不一次打开所有文件。

搜索结果中的“内容未读”状态保持到实际读取相关页或题目。学科、年级、主题、答案版等文件名线索只作候选标签；按教学目标判断用途，不因新收录而降低题目质量要求。

## 读取与采用

1. 从匹配资料中选少量最相关文件，使用宿主已有的文件、PDF、文档或图片工具读取。PDF先找目录或相关页；DOCX可读取段落、表格和内嵌图，但提取文字未必保留公式或图示。
2. 扫描PDF、截图用可用的视觉/OCR能力查看相关页；逐项核对数字、公式、选项与图表。DOC、压缩包、加密文件或不支持的格式标为待转换/待查看，使用已有的受支持工具处理；不得把后缀改成DOCX假装转换成功。缺少读取能力就说明尚未读到，不编题干。
3. 只有完整题干、关键图表与条件可读后才选入教学。需要答案核对时读取对应解析；学生版不附含答案的原文件链接或暴露答案的文件名。
4. 教师版逐题记录资料绝对路径、PDF文件页码或文档章节及原题号；印刷页码与PDF页序不同时区分。多份资料可能包含同题，实际比较后去重，不按文件数估计独立题量。
5. 纳入共同题目清单，按本技能的学科检查独立求解，并同步教师与学生两版。题源与年份未核实时如实注明。

用户说“看一下新题”时，先给资料变更摘要；需要逐题介绍时，再读取对应新增或修改资料，说明实际查看了哪些页、哪些题。读取范围有限时按范围报告，不声称已读全库。
