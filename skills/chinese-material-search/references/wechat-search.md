# 公众号检索与附件核验

用于用户优先微信公众号，或通用搜索只找到摘要、转载和领取说明的情况。先使用当前可用的网络搜索与浏览工具，不假设已经登录微信、具备公众号接口或能够读取每篇文章。

## 从主题找到文章

第一轮可并行尝试公众号定向与原发来源查询。以下是可替换的查询模板，不是已找到的结果：

```text
site:mp.weixin.qq.com 主题 讲义
site:mp.weixin.qq.com 主题 试题 解析
主题 课件 公众号
主题 大学 课程 讲义 site:edu.cn
```

按需求把材料类型换成教案、实验、教材、技术文档、科研方法或综述，并加入学段、学科、版本或常见别名。用户没有限制年份时，不为了追新排除仍适用的经典资料；要求最新版本时核对发布日期和原始版本。

站外检索未命中公众号直链时，再做一轮去掉域名限制、换主题别名或用文章完整标题的查询。已有可用的微信/搜狗微信搜索或用户授权浏览器时，可使用当前能访问的入口；入口不可用、出现验证码或需要登录时记录情况，转向其它可读来源。不要安装未知爬虫或反复请求同一个受限地址。

优先留意与主题相关的高校/学院、教研机构、出版社、学会、教师和作者账号；账号类别用于组织候选，不代表内容已经核实。公众号名称与主体以实际取得的页面或搜索结果为准，不凭印象补写推荐名单。

## 打开、定位与有限替代

1. 打开候选文章，查看正文、作者/账号、日期和原文链接。若内容主要在图片里，用已有视觉能力查看相关图片；没有读到的图表保持未核实。
2. 正文受限时，用准确标题＋作者/账号名寻找公开的原发网页、同作者发布或转载。可用已见的短语辅助定位；核对标题、作者、日期与主题是否同源，注明实际阅读的是哪个页面。
3. 每个候选至多尝试一次替代路径，再失败就记为受限。整个主题可在一轮换词检索后转向其它来源；用户另行要求深挖时再扩展。搜索无命中仅说明本轮未找到，不能推断资源不存在。
4. 对“阅读原文”、附件名或公开下载链接，分别检查链接指向和当前访问状态。跳到登录、领取表单、网盘、付费页面或失效页时，记录条件，不把这些页面当成文件本体。
5. 文章要求“关注后回复某关键词”时，只引用已看到的领取条件，不发送回复、不索取用户账号。摘要里只提到“资料见文末”时，连文末入口也尚未核实。

## 文件状态的边界

| 实际证据 | 可以报告 |
| --- | --- |
| 搜索结果有标题和若干段落 | 候选文章，正文仅部分可见 |
| 网页正文读到附件说明 | 已读该说明，文件未取得 |
| 网盘/下载页打开成功 | 入口可访问；不能据此保证文件可下载或完整 |
| 文件已下载但尚未打开 | 已取得，内容与完整性待检查 |
| 文件实际打开并检查相关内容 | 报告已检查的格式、范围和用途；整份完整性需另行核对 |

不把收费、登录或反爬提示解释成资源不存在，也不把公开网页自动解释成开放许可。用户要的资料仍可按已核实范围列出链接、用途和获取条件，避免让访问限制淹没可用结果。
