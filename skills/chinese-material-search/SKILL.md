# 中文资料检索

围绕用户当前主题实际联网，找到可用资料和原始入口，说明适合什么用途、看到了哪些内容、附件是否取得。优先检索微信公众号，也覆盖高校、作者主页、教研机构、出版社、公开课程、技术文档与用户指定平台。

## 明确这次要找什么

复用聊天中已有的主题、学段或专业程度、用途、格式、版本和时间范围。缺少普通偏好时采用合理默认并注明；连主题都未知时问一个关键问题。不要因“中文”就把大学或科研资料套进高中课程。

用户只要资料时，交付筛选结果；需要讲解、备课或综述时再完成对应成品。具体论文、DOI、引文和全文定位配合 `paper-lookup`；系统综述才使用 `literature-review`，普通资料查找不扩大成综述项目。

## 检索与筛选

1. 用主题及常见别名，搭配所需材料类型与适用程度设计查询。实际使用宿主的搜索和浏览工具；不得把计划中的查询写成已执行。
2. 默认第一轮包含微信公众号定向查询和不限平台的原发来源查询；需要较多资料时并行搜索独立方向。微信公众号的查询、阅读和替代路径见 [公众号检索与附件核验](references/wechat-search.md)。用户只指定某个平台或不希望联网时遵从要求。
3. 微信之外，按任务找作者、高校课程、官方机构、出版社、学会、公开项目或专业社区。视频、笔记与资料合集可用于发现线索；科学结论、版本和题源尽量回到原文。不要只搜一个域名就声称“全网没有”。
4. 打开最相关结果，核对标题、作者或机构、发布日期/版本、适用对象及实际可读内容。优先挑适合本次用途的少量资料，通常3—6项足够；用户要更多或范围较大时再分批扩展，不为凑数放入不相关合集。
5. 用完整标题、作者和内容线索辨别转载与重复，优先保留信息完整的原发入口。不同版本分别记录。未找到同源证据时，不把近似标题的另一份文件当成原文附件。
6. 已有资料足够支撑用户目标就停止。缺少某类资料时说明本次搜索范围和具体缺口，再给可用替代，不因一个平台受限而停住整个任务。

## 正文与附件分开核验

正文标明“已读相关全文/页面”“部分可读”“仅摘要或目录”“受限”。文章里提到文件、展示封面或写“回复关键词领取”，只能证明有该说明，不能证明已经取得文件。

附件分别标明：未见入口、仅见领取说明、发现入口但未验证、链接可访问、已取得但未检查、已打开检查，或失效/受限。只有实际打开文件，才报告其格式、页数、完整性或具体题目内容。PDF直链在搜索端有摘要但打开失败时，记为部分内容可见、文件访问未核实。

公开可读、免费领取、可下载与开放许可分别记录。没有看到许可时写“未注明”，仍可提供公开页面链接和基于已读内容的简介；不自行断言所有中文资料都已开源，也不因许可未注明就放弃普通检索。引用与使用遵守已知许可和工具限制，不复制整套受限资料。

登录、关注、回复关键词、入群、付费等条件如实列出，由用户决定下一步；本技能不自动向公众号或他人发送消息，不替用户付费或提交信息。普通抓取失败时，可用已有、获授权的浏览器查看公开页面，不绕过验证码、付费或登录限制。

## 交付结果

先给最适合当前用途的资料，再给尚待核实的候选。每条按以下字段组织，可用紧凑表格或短条目，避免堆砌空列：

| 字段 | 要交代的内容 |
| --- | --- |
| 资料与入口 | 准确标题、作者/机构或公众号、直接链接；来源不明据实注明 |
| 适用与内容 | 学段或深度、材料类型、版本/日期、当前用途；只描述已读范围 |
| 正文状态 | 实际看到了哪些页面、段落、图表或视频片段 |
| 附件状态 | 文件入口、取得/检查状态及领取条件；无附件就注明 |
| 来源与限制 | 访问日期、许可/分享说明（未注明即据实写）、尚未核实项；共同访问日期可合并说明 |

实际内容不足以判断质量时，把该项放在候选中，不写成“已核验推荐”。用户只是找链接时压缩说明，仍保留关键访问限制；需要成品时在采用的事实或题目旁保留来源。

## 与备课和本地题库协作

高中数理化生备课时，为 `high-school-lesson-prep` 提供网络材料及阅读状态；由备课流程决定选题、独立核解和教师/学生两版。已经完成的搜索和正文读取复用结果，不重复执行同一轮。

作为高中备课流程的一部分运行时，读取其 [主题资料搜集、下载与归档](../high-school-lesson-prep/references/online-material-collection.md)。当前用户已允许下载并指定保存目录时，执行该范围内的下载与归档；尚未授权下载时只提供链接与读取状态。用户当次限制离线、只给链接或不下载时遵从要求。此约定不把其它主题的普通资料查询一律变成下载任务。

其它普通资料查询默认交付链接与资料说明。用户要求下载、整理或加入题库时，再保存其要求的公开可获取文件，保留来源链接与获取日期。先核对本地文件确实存在，并分别说明是否已打开检查；文件打不开或内容不符时报告实际情况，不能把登录页当成下载成功的资料。加入 `<用户指定题库目录>` 后可调用已有题库扫描器更新索引；上述备课流程入库后必须更新，均需区分本地新增文件与新命题。搜索请求本身不创建定时监控或后台推送。
